Daftar Proxy

Satu proxy per baris. Format yang didukung:

  • host:port — HTTP default
  • host:port:user:pass — HTTP dengan autentikasi
  • socks5://host:port:user:pass — SOCKS5 dengan autentikasi
  • http://host:port — HTTP eksplisit

Import dari Supabase

Ekstensi akan fetch REST Supabase kamu dan mengganti bagian "remote" dari daftar (list manual di atas tetap). Di-refresh otomatis tiap browser dibuka.
